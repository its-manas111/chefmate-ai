Overview

This page clarifies two roles: the runtime architecture powered by Foundry and Azure AI, and the development assistance pattern powered by GitHub Copilot. It keeps the diagram focused and easy to scan.

Key points

Microsoft Foundry is represented by the Python wrapper and agent layer. It is the core runtime path for generating recipe recommendations from structured prompts.

GitHub Copilot is shown as a non-runtime tool that helps developers implement and document the project. It completes code suggestions but is not part of the deployed application flow.
