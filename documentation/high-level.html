Overview

This diagram maps the major systems: the React + Vite frontend, the Express API backend, Azure OpenAI Vision, and the Python Foundry wrapper. It keeps interactions easy to scan and focuses on the main request/response relationships.

Key takeaway

The solution is intentionally layered: UI handles user input, the API manages routing, vision extracts ingredients, and the Python/Foundry layer generates recipes. This separation makes the system easier to maintain and extend.
